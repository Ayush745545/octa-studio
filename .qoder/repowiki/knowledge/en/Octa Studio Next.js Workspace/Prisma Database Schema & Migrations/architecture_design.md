Single Prisma schema (`schema.prisma`) declares five models — `Idea`, `Content`, `Media`, `PublishingChannel`, `Publication` — all backed by a PostgreSQL datasource. Relations are modeled as foreign keys: `Content` optionally belongs to an `Idea` (set-on-null), while `Media` and `Publication` cascade-delete on content/channel removal; `Publication` is uniquely constrained per `(contentId, channelId)`. The generated Prisma client is emitted to `../app/generated/prisma`. Evolution is tracked via timestamp-prefixed migration folders under `migrations/` (e.g., `20260811122549_add_idea`, `20260812122000_add_publishing_channels`) managed through Prisma's migration lock file.
