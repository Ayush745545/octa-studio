The root orchestrates four child modules through Next.js conventions: `app_pages` provides the App Router entry points (pages, server actions, API routes) that import React client components from `components`, consume the Prisma client singleton from `lib_shared`, and persist data via the schema in `database`. `prisma.config.ts` centralises datasource URLs (`DATABASE_URL`, `SHADOW_DATABASE_URL`) consumed by both the generated Prisma client and migrations under `database/prisma/migrations`. `next.config.ts` configures dev CORS origins for the whole app, while `vercel.json` wires a cron to `/api/publishing/process` so the publishing engine runs server-side without user interaction. All children share the same TypeScript/Next.js runtime, Tailwind v4 styling pipeline, and Prisma adapter (`@prisma/adapter-pg` + `pg`).
