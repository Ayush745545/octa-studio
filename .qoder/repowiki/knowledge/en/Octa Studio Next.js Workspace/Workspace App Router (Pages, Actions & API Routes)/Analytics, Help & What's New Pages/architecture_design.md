Four sibling Next.js App Router route segments under `app/`, each exporting a default page component wrapped in `WorkspaceLayout` from `@/components/layout/workspace-layout`. The `analytics/page.tsx` is a server component with `export const dynamic = "force-dynamic"` that queries Prisma (`prisma.content`, `prisma.idea`) to compute counts by status (DRAFT, READY, SCHEDULED, PUBLISHED), recent activity over the last 7 days, platform distribution, publishing rate, upcoming scheduled items, and recent updates — all fetched via `Promise.all` and rendered as static Tailwind-styled cards and charts. The other three pages (`custom-analytics`, `help`, `whats-new`) are minimal placeholder components displaying an 'under construction' message; they reuse the same layout wrapper and styling pattern but perform no data fetching.
