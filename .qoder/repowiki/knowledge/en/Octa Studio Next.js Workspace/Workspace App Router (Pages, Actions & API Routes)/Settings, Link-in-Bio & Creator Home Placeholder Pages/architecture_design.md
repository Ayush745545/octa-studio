Three sibling Next.js App Router route segments (`app/settings`, `app/link-in-bio`, `app/creator-home`), each exporting a default page component from a single `page.tsx`. Every page composes the shared `WorkspaceLayout` from `@/components/layout/workspace-layout` with `activeItem="custom-analytics"` to integrate into the app's sidebar navigation. The pages themselves are thin presentational shells — no data fetching, state, or business logic — serving as scaffolding for future feature implementations.
