Two sibling Next.js App Router route groups under `app/`:
- `app/ideas/` is a server-rendered feature. `page.tsx` fetches all ideas via Prisma (`prisma.idea.findMany`) and renders them inside `WorkspaceLayout`, while `[id]/page.tsx` loads a single idea and calls `notFound()` when missing; mutation is delegated to a server action in `actions/create-idea.ts` that validates input, persists via Prisma, and calls `revalidatePath("/ideas")`. UI components (`NewIdeaModal`, `TurnIntoContentButton`) live in `@/components/ideas/`.
- `app/ai-studio/page.tsx` is a full client component (`"use client"`) that owns all state (active tab, generations history, pipeline steps, image/video results) and drives three external backends: an `/api/ai/generate` endpoint for text/image/video generation, and the `createContent` server action from `@/app/content/actions/create-content` to persist generated drafts into the content pipeline.
Dependency direction is one-way: both pages depend on shared layout (`WorkspaceLayout`), Prisma, and reusable UI components; the AI Studio page additionally depends on the content creation action and the AI API route.
