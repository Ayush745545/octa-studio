Three top-level files compose the application shell under Next.js App Router:
- `app/layout.tsx` defines the root `RootLayout`, exporting a `Metadata` object for SEO and wrapping all routes in an `<html>`/`<body>` tree. It injects three Google Fonts (Geist Sans, Geist Mono, Inter) as CSS custom properties (`--font-geist-sans`, `--font-geist-mono`, `--font-inter`) and applies a full-height flex column body with `antialiased`.
- `app/globals.css` is imported by the layout and serves as the single source of global styles: it imports Tailwind v4 via `@import "tailwindcss"`, declares dark-mode color tokens (`--background`, `--foreground`, zinc palette), maps font variables into Tailwind's `@theme inline` namespace (`--font-sans`, `--font-mono`, `--font-display`), and defines reusable keyframe animations (`modal-in`, `overlay-in`, `slide-in-right/left`, `fade-in/out`, `toast-in/out`) plus utility classes (`.headline`, `.apple-font`).
- `app/page.tsx` is the route handler for `/`, marked `force-dynamic` so it runs on every request. It queries four Prisma models concurrently (`idea.count`, `content.count`, `content.count({status:"PUBLISHED"})`, `publishingChannel.count({connected:true})`) inside a try/catch and passes the results as props to the client component `LandingClient` from `@/components/landing-client`.
Dependency direction is one-way: this module depends on shared libraries (`@/lib/prisma`, `@/components/landing-client`) and global CSS; nothing in the app imports these files except the Next.js router itself.
