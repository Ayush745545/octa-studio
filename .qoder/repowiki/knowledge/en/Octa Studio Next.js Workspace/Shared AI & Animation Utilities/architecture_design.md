Three independent sub-packages under `lib/` with no cross-dependencies between them:
- `prisma.ts`: Server-side singleton that instantiates a single `PrismaClient` backed by the `@prisma/adapter-pg` PostgreSQL adapter, reuses it across hot-reload via a `globalThis` cache, and enforces `DATABASE_URL` at import time.
- `ai/`: A ComfyUI integration split into a transport layer (`comfyui.ts` — `ComfyUIClient` class exposing `submitWorkflow`, `pollUntilComplete`, `downloadFile`, `checkHealth`) and composable workflow factories under `workflows/` (`image.ts` builds SDXL KSampler pipelines, `video.ts` builds Wan2.1 video pipelines). Workflows are plain JSON graphs typed as `ComfyUIWorkflow` and submitted to the `/prompt` endpoint; results are polled on `/history/{promptId}` until completion or timeout.
- `animations/`: Client-side utilities for Next.js App Router. `gsap.ts` is the single registration point for GSAP + ScrollTrigger; `scroll.ts` exposes React hooks (`useGSAPScrollTrigger`, `usePinnedSection`, `prefersReducedMotion`) that wrap ScrollTrigger in `gsap.context()` with proper cleanup; `smooth-scroll.ts` (marked `'use client'`) integrates Lenis with GSAP's ticker and ScrollTrigger update loop.
Dependency direction is strictly outward: consumers import from these modules; there are no imports back into app routes from here.
